# Ineza Clinic – Patient Support Management System

A standalone browser-based patient support management demo built with **HTML, CSS and vanilla JavaScript**.

## Features
- Admin demo login
- Dashboard with patient, support, appointment and doctor statistics
- Patient registration, search, edit and delete
- Patient support requests with priority and status tracking
- Appointment booking and status updates
- Doctor directory
- Responsive desktop and mobile layout
- Browser `localStorage` persistence

## Run the application
1. Extract the ZIP file.
2. Open the `ineza_clinic_patient_support` folder.
3. Double-click `index.html` to open it in a modern browser.

No installation, server, database or build process is required.

## Important limitations
This is a standalone demonstration application. Data is stored in the browser on the device where it is used. It does not provide a secure server, real multi-user access, cloud backup, or integration with clinic systems. Do not enter real patient medical or personally identifiable information. A production clinic system needs secure backend services, access controls, audit logs, backups and privacy/security review.
